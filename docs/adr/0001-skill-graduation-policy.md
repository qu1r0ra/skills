# Skills default to this collection; standalone repos require a technical forcing function

The retired `adversarial-review-agy` skill once had a standalone repo because its external paid CLI needed a distinct install and trust boundary. Its sibling `adversarial-review` remained in this collection. Both skills were retired on 2026-09-28; their history prompted this still-active decision: skills stay in `qu1r0ra/skills` by default. A skill graduates to a standalone repo only when its install, trust, dependencies, or CI require a separate home. Public visibility alone is not a reason to split it out.
